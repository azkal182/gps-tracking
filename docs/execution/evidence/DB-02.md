# DB-02 — Migrasi domain, positions dan locking

Tanggal: 2026-10-19  
Status: selesai

## Hasil

- Menambahkan `202610190003_tracking_domain.sql`: targets, devices, device credentials, application tokens/resource allowlists, tracking sessions, positions, idempotency records dan audit events.
- Tenant-owned relations memakai tenant composite foreign keys. Tabel memiliki unique/check constraints serta indeks untuk identity, lookup, history, expiry dan audit.
- Session intervals memakai `tstzrange [start,end)`, GiST exclusion untuk mencegah interval device yang tumpang tindih, dan partial unique indexes untuk satu sesi aktif per target/per device.
- Posisi menyimpan geography WGS84, fingerprint, dedupe `(device_id,message_id)` dan `expires_at` tersimpan untuk satu tahun kalender UTC (29 Februari menjadi 28 Februari). Retensi dilakukan melalui expiry index; worker purge berada di task berikutnya.
- Application token memiliki FK membership tenant, allowlist device/target tenant-scoped dan deferred constraint yang melarang token tanpa resource scope.
- Menambahkan helper transaksi `lock_tracking_resources`: organization shared lock, device UUID ascending, target UUID ascending, session UUID ascending.
- Memperluas tes PostgreSQL untuk migration upgrade, tenant FK, resource allowlist, credential uniqueness, idempotency/dedupe, timestamp expiry, session exclusion/active uniqueness, race start-session dan pemanggilan lock-order serentak dengan daftar ID terbalik.

Application token dimasukkan bersama domain migration karena allowlist-nya membutuhkan FK ke target/device tenant-composite; migration identity/auth sebelumnya belum memiliki tabel resource tersebut.
